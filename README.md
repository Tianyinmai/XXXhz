# XXXhz
请开发一款Python随机密码生成器，详细要求如下：
1. 核心功能：
   - 支持自定义密码长度（6-32位，默认16位）；
   - 支持选择字符类型（数字、小写字母、大写字母、特殊符号，可多选）；
   - 支持批量生成（1-100个密码，默认1个）；
   - 支持密码强度检测（生成后标注密码强度：弱/中/强）。
2. 扩展功能：
   - 生成的密码保存到本地`passwords.json`文件（格式：{"生成时间": "...", "密码列表": [...], "强度": [...]}）；
   - 支持排除易混淆字符（如0和O、1和l）；
   - 支持一键复制生成的密码到剪贴板（借助`pyperclip`库）。
3. 代码要求：
   - 拆分模块：`core/password_generator.py`（生成逻辑）、`cli/menu.py`（交互）、`utils/strength_checker.py`（强度检测）、`utils/clipboard.py`（剪贴板操作）、`main.py`（入口）；
   - 异常处理：拦截密码长度小于6/大于32、批量生成数量大于100等非法输入；
   - 注释完整：核心函数添加docstring，说明参数、返回值、功能。
4. 交互要求：
   - 菜单示例：
     ===== 随机密码生成器 =====
     1. 生成单个密码
     2. 批量生成密码
     3. 查看历史生成记录
     4. 清空历史记录
     0. 退出程序
     请选择功能（0-4）：
   - 输出示例（生成单个密码）：
